# Movie Collection 🎬

A Flask web app for creating and managing a personal top 10 movie collection.

## Built With

- Python
- Flask
- Flask-SQLAlchemy
- Jinja
- WTForms
- Bootstrap
- The Movie Database API

## Features

- Search for movies using the TMDB API
- Add movies to a personal collection
- Edit movie ratings, reviews, and rankings
- Delete movies
- Display movies ordered by ranking
- Store movie data in SQLite

## CRUD

- **Create** Add movies to the collection
- **Read** View movies and their details
- **Update** Edit ratings, reviews, and rankings
- **Delete** Remove movies from the collection
