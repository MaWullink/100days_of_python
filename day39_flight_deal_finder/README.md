# Flight Deal Finder ✈️

A Python project that searches for affordable flights using the Google Flights API and automatically updates destination prices in a Google Sheet.

## Built With
- Python
- Requests
- SerpAPI
- Sheety API
- Requests Cache

## Features
- Retrieve destination data from a Google Sheet
- Search flights between multiple destinations
- Find the cheapest available flight
- Compare flight prices with saved target prices
- Automatically update the spreadsheet when a cheaper flight is found
- Cache API requests to reduce unnecessary calls
