# Cafe & WiFi API ☕️

A Flask REST API for finding and managing cafes.

## Built With

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- Postman

## Features

- Get all cafes
- Get a random cafe
- Search for cafes by location
- Update cafe information
- Delete cafes
