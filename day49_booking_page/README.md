# Gym Class Booking Bot 🏋️

A Python Selenium project that automatically logs into a gym booking website and books workout classes based on user input.

## Built With

* Python
* Selenium
* Chrome WebDriver

## Features

* Automatically log into the gym website
* Use a custom Chrome profile to save browser settings
* Choose a workout day, class type, and time through the console
* Dynamically find classes using CSS selectors
* Check if a class is already booked or waitlisted
* Automatically book available classes or join the waitlist
