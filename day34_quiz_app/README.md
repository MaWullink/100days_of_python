# Quizzler ❓

A Python True/False quiz application with a graphical user interface built using Tkinter. The program loads questions from a data source, tracks the player's score, and provides instant feedback after each answer.

## Built With
- Python
- Tkinter
- HTML module

## Learned
- Object-oriented programming
- Creating GUI applications with Tkinter
- Managing application state
- Working with classes and objects
- Handling user input through buttons
