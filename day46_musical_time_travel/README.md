# Billboard to YouTube Music Playlist 🎵

A Python project that scrapes the Billboard Hot 100 for a chosen date and automatically creates a matching playlist in YouTube Music.

## Built With

* Python
* Requests
* Beautiful Soup
* YTMusicAPI

## Features

* Enter a date to retrieve the Billboard Hot 100 songs
* Scrape the top 100 songs from the Billboard chart
* Authenticate with YouTube Music
* Create a new playlist for the selected date
* Search for matching songs on YouTube Music
* Automatically add the songs to the playlist
